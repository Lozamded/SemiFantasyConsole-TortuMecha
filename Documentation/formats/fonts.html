Fonts

Two independent formats for text: .tortufont bakes a TTF into palette-index glyph bitmaps, .tortuspritefont is hand-painted sprite-sheet glyphs.

Both share the same per-glyph shape (a TortoiseGlyph) and are keyed by Unicode code point, but they're built completely differently — pick .tortufont to reuse an existing typeface, .tortuspritefont to hand-draw pixel-art glyphs.

The glyph shape (shared by both formats)

FieldTypeDefaultNotes
width / heightintrequiredGlyph cell size in pixels.
advanceintrequiredPixels to move the cursor forward after drawing this glyph — can differ per-glyph even within one font.
pixelslist[int]requiredFlat, row-major, length width*height, palette indices.
bearing_x / bearing_yint0Draw offset within the cell.

On disk, glyphs are a JSON object keyed by str(code_point): {"32": {...}, "65": {...}, ...} — loaded into an in-memory dict[int, TortoiseGlyph]. Loaders accept legacy w/h as aliases for width/height per glyph.

.tortufont — TTF-baked glyph atlas

Not a re-exported TTF — a fully rasterized bitmap cache in palette-index form, plus a pointer back to the source TrueType file for re-baking.

FieldTypeDefaultNotes
namestrrequired
sourcestrrequiredProject-relative path to the .ttf file. Loading raises if missing/blank.
sizeint8Point size passed to pygame.font.Font when baking. The documented 4–32 range (MIN_FONT_SIZE/MAX_FONT_SIZE) is a UI-slider bound only — not enforced by the loader.
line_heightint10See the auto-correction note below.
palettestr"default"
charset_presetstr"latin1""ascii" (chr 32–126), "latin1" (chr 32–255), or "custom".
charsetstr""Only used when charset_preset == "custom" — the literal character set string.
glyphsdict{}See above.
line_height self-heals on every load/save Both load_tortu_font() and save_tortu_font() call a step that raises line_height to at least the tallest baked glyph's height. If you hand-edit glyph pixel data to a taller cell without also bumping line_height, the next load/save round-trip fixes it automatically — but until then, text may render clipped.

Baking (rebuild_font_glyphs) renders each character in the resolved charset white-on-transparent via pygame.font.Font, converts every pixel to the nearest palette index (alpha < 128 → the transparent index), and sets advance = max(1, font.size(char)[0]) per glyph.

{
  "name": "VCR", "source": "assets/fonts/VCR.ttf",
  "size": 20, "line_height": 20, "palette": "default",
  "charset_preset": "latin1", "charset": "",
  "glyphs": {
    "32": {"w": 12, "h": 18, "advance": 12, "bearing_x": 0, "bearing_y": 0, "pixels": [ ...216 ints... ]}
  }
}

.tortuspritefont — hand-painted sprite-sheet glyphs

FieldTypeDefaultNotes
namestrrequired
palettestrrequired
glyph_blocks_w / glyph_blocks_hint2 / 2Glyph cell size in 4px sprite blocks — always a multiple of 4px, same block unit as sprites. Legacy alias: blocks_w/blocks_h. Minimum 1 block, enforced; the documented max of 8 blocks is not enforced.
line_heightint0
default_advanceint0Used when a glyph doesn't specify its own advance.
charsetstr""See below — can be a subset of what actually resolves.
glyphsdict{}
A fixed base charset can't be removed Every sprite font always includes a baseline set — space, A–Z, a–z, 0–9, .:+-/% — regardless of what's stored in charset. resolved_charset() prepends this base set, then appends any extra characters the file's charset adds; trying to remove a base character is a silent no-op. So the stored charset on disk can legitimately be a strict subset of what the font actually resolves to at runtime.

After any charset change, every character in the resolved charset is guaranteed a glyph entry — missing ones get a synthesized blank glyph (all pixels transparent, advance = default_advance or pixel_width) rather than being left absent.

{
  "name": "hud", "palette": "default",
  "glyph_blocks_w": 2, "glyph_blocks_h": 2, "line_height": 8, "default_advance": 8,
  "charset": "",
  "glyphs": {
    "32": {"w": 8, "h": 8, "advance": 7, "bearing_x": 0, "bearing_y": 0, "pixels": [ ...64 ints... ]}
  }
}

Note the space glyph's own advance (7) overriding the font-wide default_advance (8) — per-glyph advance always wins when present.

Legacy compat on load

If a .tortuspritefont's charset is blank/absent, the loader falls back to a legacy charset_preset field (same three presets as .tortufont) or, failing that, the fixed base charset.
